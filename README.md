# 待办 (daiban-todo)

兼容 [topydo](https://github.com/topydo/topydo) / [todo.txt](http://todotxt.org) 格式的安卓待办清单（Flutter），为“按计划备考、没做完自动顺延、做完自动提前”而做。

> 许可：GNU GPL-3.0（见 [LICENSE](LICENSE)）。todo.txt 格式与任务语义（优先级、`due:`、`t:`、`x` 完成前缀、`+项目`/`@情境`）参考自 topydo
> （Copyright (C) 2014-2015 Bram Schoenmakers 及贡献者，GPL-3.0），本项目用 Dart 重新实现，并以同样的 GPL-3.0 发布。

## 功能

- **导入 / 导出**：todo.txt 文件、分享 / “用待办打开”、粘贴文本；**.ics 日历**直接导入（自动把“一天一条”的事件拆成“一项一条”任务）；导出 todo.txt / done.txt / .ics。
- **三个视图**：今日（今天 + 逾期，未到 `t:` 开始日期的不显示，**按类别分组**）、全部任务（按日期分组）、已完成（done.txt 归档）。
- **按类别独立提前 / 顺延**：类别 = 任务的第一个 `+标签`（如 `+408`、`+数学`）。
  - *完成即提前*：某类别今日任务（含逾期）全部完成后，只把该类别的下一批日期整体提前到今天；每个类别标题上还有手动“提前下一批”按钮。
  - *整体顺延*：跨天后，某类别昨天还有未完成任务，只把该类别后续未完成任务的 `due`/`t` 各推迟 1 天（打开 / 回到前台时检查，无需后台服务）。
  - 全局开关 + 每个类别单独开关（跟随全局 / 开 / 关）。
- **提前可还原**：某类别今日任务全部完成后，下一批会被提前到今天（日期改写为今天，标签显示“今日”并带“已提前到今日”）。当天如果又取消完成了今天原本的任务，刚才提前的那一批（及后续任务）会还原回原日期，只显示今天的；记录写在任务行的隐藏标签 `pf:YYYYMMDD.序号.天数` 里（界面不显示，完成时清除，隔天自动清理），所以重启或组件后台操作后仍可还原。
- **预计完成**（仅应用内，桌面组件不显示）：今日页每个类别标题下一行小字显示“进度 已完成/总数 · 计划 · 预计（提前/落后 N 天）”，「批量管理」里的类别列表显示更详细的说明。按“量”来算，不看速度：每条任务导入/新增时会记下原计划日期，写在隐藏标签 `plan:YYYY-MM-DD` 里（界面和编辑框不显示，完成后保留；“完成即提前 / 整体顺延”只改写 `due:`/`t:`，不改 `plan:`；老数据首次加载时补写，有 `pf:` 记录的按其还原）。同一原计划日的任务算“一天的量”，这一天的任务全部完成才算完成一天，只做一部分不算。提前天数 = 原计划日在今天之后且已全部完成的天数 − 原计划日在今天之前但没做完的天数；计划完成 = 原计划最后一天；预计完成 = 计划完成 − 提前天数（落后则为 + 落后天数）。手动编辑任务日期或「批量平移」视为重新计划，`plan:` 随之更新。
- **底栏**：今日、全部、锁屏、已完成、统计（锁屏在正中间）。标题跟随当前标签；「+」只在今日 / 全部出现，多选只用于今日 / 全部 / 已完成三个待办标签。
- **正向计时**（仅应用内）：今日页顶部按类别显示卡片（「正向计时 / 开始」），「批量管理」里也可以开始。同时只能进行一个计时，全屏秒表从 00:00:00 正向累加。开始后会请求 Android 屏幕固定并保持亮屏。页面上只有一个「退出」：点它或按返回键会先弹出确认，确认后解除固定、中断本次计时并记录；「结束并记录」记为正常完成。用系统手势解除固定时同样中断并记录。正向计时的退出不计入「中断次数」。记录写在 `focus.json`，进行中的一次还写在设置里，杀进程后仍可接着计；超过 12 小时未结束的会在下次打开时自动记为中断。
- **锁屏倒计时**（底栏「锁屏」）：选类别（任务类别 + 有专注记录的类别 + 未分类）和时长（25 / 45 / 60 / 90 分钟或自定义小时 + 分钟，会记住上次的选择），点「开始」后请求屏幕固定、保持亮屏并倒计时。固定后应用界面不提供任何退出方式（没有退出 / 结束按钮，返回键无效）；到点自动解除固定、按计划时长记为完成并提示。屏幕固定没开或被拒绝时会说明如何开启，不会进入锁定状态。正向计时进行中时会先询问是否结束并记录它。进行中的倒计时保存了结束时刻：进程被杀后重新打开，若未到点会恢复锁定视图并重新请求固定，若已过点则记为完成。若被系统手势解除固定，计时满 10 秒的记为中断。记录里以「锁屏」标注。
- **统计数据**（底栏「统计」，桌面组件不显示）：累计专注（次数、时长、日均时长＝总时长÷有记录的天数、中断次数）、可翻页的当日专注（次数、时长、中断次数）、专注时长分布（日 / 周 / 月 / 自定义，饼图、占比、分享为图片、查看专注记录）以及本月专注时段分布（按 0–23 时累计）。次数和时长记在开始的那一天，正向计时和锁屏都计入；时段分布按实际跨越的小时拆分。「中断次数」只统计锁屏倒计时被中断的次数，正向计时的退出不算。记录列表里中断的标「已中断」，锁屏的标「锁屏」。
- **分享统计图片**：「专注时长分布」旁的「分享」会生成一张 PNG 图片（不是文字）并调起系统分享面板。图片里同时画出饼图（当前选中的日 / 周 / 月 / 自定义周期及日期范围、各类别颜色与占比图例）和本月专注时段分布柱图（0–23 时，当前显示的月份），上方附累计 / 当日的次数、时长、日均时长和中断次数；没有记录时也会生成带空状态的图片。图片临时存放在应用缓存目录，通过 FileProvider 分享，不需要额外权限。
- **批量管理**：删除全部、清空已完成、按类别删除 / 重命名合并；列表里长按进入多选，批量完成 / 删除 / 更改类别 / 平移日期；绝大多数操作可撤销（一步）。
- **桌面组件**：把「待办 · 今日」放到主屏幕（默认 2×2，可横向/纵向调整大小）。按类别列出今天未完成的任务，点勾选框即可完成（不必打开应用，完成规则和按类别提前与应用内一致）；点标题打开应用。
- 新增 / 编辑 / 删除任务，优先级，开始日期，中文界面，数据存在应用私有目录的 `todo.txt` / `done.txt`。

## 导入格式

### todo.txt（每行一条，UTF-8）

```
(A) 数据结构 KMP 手算 next/nextval（p117-118） +408 +数据结构 due:2026-11-11 t:2026-11-11
数学 极限与连续习题 +数学 due:2026-11-12 t:2026-11-12
x 2026-11-10 背单词 +英语 due:2026-11-10
```

- `(A)` 优先级；`x 完成日期 …` 表示已完成；`+项目`、`@情境` 标签；
- `due:YYYY-MM-DD` 截止日期，`t:YYYY-MM-DD` 开始日期（未到这天不出现在“今日”）；也支持 `due:明天`、`due:3d`、`t:+1w` 这类相对日期；全角冒号 / 括号会自动规整；
- **类别** 是第一个 `+标签`。导入时会弹出对话框，可以把类别设为某个名字（成为第一个 `+标签`），并选择保留或清除原有其它标签。

### .ics 日历

- 支持 `VEVENT` 的 `DTSTART` / `DTEND`（DATE 与 DATE-TIME，`DTEND` 不含当天），行展开，`\n \, \;` 转义，多日事件按天展开；
- 默认类别取日历名 `X-WR-CALNAME` 的第一个词；`SUMMARY` 第一个词作为科目标签；
- `DESCRIPTION` 会按 “；”“。”、上午/下午、“，”“、”拆成一项一条的学习任务（页码 `pXX-YY` 与【重点】标记跟随所在条目），逻辑见 `lib/logic/plan_splitter.dart`；
- 命令行转换：`dart run tool/ics_to_todo.dart 输入.ics 输出.txt`。

## 添加桌面组件

1. 先打开一次「待办」并导入或添加任务（这样组件才能拿到今日列表，并注册后台勾选回调）。
2. 长按桌面空白处 → 选择「微件 / 小组件 / Widgets」→ 找到「待办」→ 把「待办 · 今日」拖到桌面。部分系统也可以长按应用图标，再选「微件」。
3. 默认大小为 2×2 格，可拖边框或双指缩放，横向、纵向都能调。
4. 点标题打开应用；点任务左侧勾选框即可完成该条。完成后若该类别今天已经没有未完成任务，会按设置自动提前下一批。

## 构建

需要 Flutter 3.35+、JDK 17、Android SDK（platform 34+）。

```bash
python3 tool/gen_icons.py          # 生成启动图标（需要 pillow；仓库不含二进制图标）
flutter pub get
flutter analyze
flutter test
flutter build apk --release --split-per-abi --target-platform android-arm64,android-arm
```

产物在 `build/app/outputs/flutter-apk/`，默认使用调试证书签名，可直接侧载；要上架请自行配置签名密钥（不要把密钥提交进仓库）。
GitHub Actions（`.github/workflows/release.yml`）可手动触发，自动构建并把 APK 发布到 Release。

## 已知限制

- 不支持 topydo 的 `rec:` 重复任务、依赖、子任务；这些标签会原样保留但不生效。
- 没有通知提醒。跨日顺延会在打开 / 回到前台时执行，桌面组件也会在大约 0:01 或最多约 30 分钟的周期刷新时触发一次。勾选组件后需等后台任务跑完（约一两秒）才会刷新列表。
- 撤销只保留上一步。
- 屏幕固定会先出现系统提示，需要用户确认；部分机型可能限制或无法固定。Android 仍然可以用系统手势（例如同时按住返回和概览键）解除固定，应用无法阻止：此时无法先弹出自建对话框，正向计时和锁屏倒计时都会立即中断并记录（锁屏不足 10 秒不记）。
